# 🚀 Simple SaaS Landing Page

A clean and modern landing page for a Software-as-a-Service (SaaS) product. Built with, React + Tailwind CSS, it's responsive, fast, and easy to customize.

## ✨ Features

- Responsive design for all screen sizes
- Hero section with CTA
- Product features showcase
- Pricing plans
- FAQ section
- Testimonials section
- Download sectiom
- Footer with links and contact info

## 🔧 Tech Stack

- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)

## 📦 Installation

```bash
git clone https://github.com/yourusername/saas-landing-page.git
cd saas-landing-page
pnpm install
pnpm  dev
```
